# 📝 Todo List App

A simple and clean Todo List web application built with **HTML**, **CSS**, and **JavaScript**. Tasks are saved to `localStorage` so they persist even after refreshing the page.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed (with a checkmark)
- Delete tasks
- Tasks persist after page refresh (localStorage)
- Clean and responsive UI with a gradient background

---


## 🛠️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/todo-list-app.git
   ```

2. Navigate into the project folder:
   ```bash
   cd todo-list-app
   ```

3. Open `index.html` in your browser — no server or installation needed.

---

## 💻 Usage

| Action | How |
|---|---|
| Add a task | Type in the input field and click **Add** |
| Complete a task | Click on the task to toggle the checkmark |
| Delete a task | Click the **×** button on the right |
